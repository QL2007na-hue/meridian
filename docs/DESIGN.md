# Meridian 设计规范

> 一套设计，不是一套组件库。改任何视觉决定之前先读这一页。

## 1. 定位

Meridian 是一台放在桌上的「时计」：iPad 横屏常亮，99% 的时间它只做一件事——用尽可能清楚、尽可能安静的方式告诉你现在几点。待办、专注、世界时钟是它允许自己拥有的全部附加内容。

**气质：** 石墨黑 + 骨白 + 一点灯下的琥珀。像一块精密仪器，不像一块广告牌。

**判断标准：** 拿掉任何一个元素，时钟是否更清楚？如果是，就拿掉。

## 2. 色彩（唯一来源：`ios/Meridian/Design/Theme.swift`）

| Token | 值 | 用途 |
| --- | --- | --- |
| `Palette.canvas` | `#08090B` | 画布。不是纯黑，留一点暖调，避免 OLED 上死黑、避免琥珀色振颤 |
| `Palette.canvasLift` | `#0D0E11` | 设置页底色、抬升表面 |
| `Palette.ink` | `#F4F1EC` | 主文字与时间数字（暖白，不是纯白） |
| `Palette.inkSecondary` | `#A9A39B` | 次要信息、未激活状态 |
| `Palette.inkTertiary` | `#6F6A63` | 标签、说明 |
| `Palette.inkQuaternary` | `#46433F` | 弱化信息、分隔文字 |
| `Palette.ember` | `#E0A662` | **唯一强调色**：现在、进度、优先、完成 |

规则：

- 一屏只有一个强调色。禁止第二个高饱和色，禁止紫蓝渐变。
- 层级靠「表面色阶 + 1px hairline + 留白」，不靠大阴影、不靠粗边框。
- 不叠两层半透明表面——可读性会塌。

## 3. 字体

系统字体（SF Pro / 苹方）。数字一律 `monospacedDigit()`，避免跳字。字体、字重、是否渐变由**外观预设**（`Core/Skin.swift`）决定，不再写死在视图里。

| 级别 | 字号 | 用途 |
| --- | --- | --- |
| Clock | `min(width × 0.205, height × 0.46)` | 主时间 |
| display | 44 | 设置页大标题 |
| title | 26 | 面板内主标题 |
| headline | 19 | 次级标题 |
| body | 15 | 正文、任务标题 |
| caption | 12 | 辅助说明 |
| micro | 10 | 大写微标签（tracking +1.6~1.8） |

字距随字号变化：大字为负（`-0.035em ~ -0.045em`），微标签为正（`+1.6~1.8pt`）。层级用「字重 + 灰度」制造，不靠堆字号。

## 3.1 外观预设

六套内置预设，全部深色画布（这样右侧面板可以只借一个强调色，不必为浅色主题做第二套中性阶）：

| 预设 | 画布 | 数字 | 字体 / 字重 | 秒环 |
| --- | --- | --- | --- | --- |
| 石墨（默认） | `#08090B` | 暖白 `#F4F1EC` | 圆体 / 细 | 刻度 |
| 悬浮蓝（iOS StandBy） | `#000000` | 蓝→天蓝渐变 `#3B76FF → #9BD8FF` | 圆体 / 粗 | 弧 |
| 灯下琥珀 | `#0B0704` | 琥珀→橙 `#E8A76A → #F0714A` | 圆体 / 细 | 刻度 |
| 极光 | `#04100E` | 薄荷→青 `#9BE8CE → #5BC8E8` | 圆体 / 中 | 弧 |
| 赭红 | `#0A0608` | 赭→珊瑚 `#E8836F → #F3B98F` | 衬线 / 细 | 刻度 |
| 纯白墨 | `#000000` | 纯白 | 无衬线 / 极细 | 无 |

自定义轴（设置 → 外观）：数字颜色（8 色板，同时改强调色与光晕）、字体（圆体/无衬线/衬线/等宽）、字重（极细→粗）、渐变开关、秒环样式。改动会把预设标记为「自定义」，存进 `state.json`。

颜色传递只有一条路：`RootView` 注入 `environment(\.skin)`，时钟读 `skin.numerals(_:)` / `skin.numeralStyle`，面板读 `skin.accentColor`。视图里再写 `Palette.ember` 就是 bug。

## 4. 间距与圆角

间距只有一套 4 基数标度：`2 / 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96`（`Space`）。

圆角：`chip 8 / card 18 / panel 26 / stage 34`（`Radius`）。同一元素内不混用两套圆角。

布局骨架（横屏 1366×1024 参考）：

```
┌─────────────────────────────────────────────┬──────────────┐
│ 顶部 rail：星期·日期 / 第 N 天      农历·节气 │ 面板标题  ●在线 │
│                                             │              │
│                                             │   卡片       │
│   21:47  ◔23          ← 时间舞台 左对齐     │  （列表/专注/ │
│   下午 UTC+8 今日已过 90%                    │    世界时钟） │
│   ──────────────●（当日进度）                │              │
│                                             │   [切换器]   │
│ ● 在线·21:46  |  今日 3/7  |  下一个 22:00   │              │
└─────────────────────────────────────────────┴──────────────┘
```

时间区宽度 = `总宽 − 360(面板) − 2×32(边距)`；面板固定 360pt。

## 5. 动效

只动 `transform / opacity / 数值`，不动布局。

| Token | 参数 | 用途 |
| --- | --- | --- |
| `Motion.settle` | spring(response 0.44, damping 0.86) | 出现、面板切换、列表变化 |
| `Motion.snap` | spring(response 0.26, damping 0.90) | 点击反馈、数字切换 |
| `Motion.drift` | spring(response 0.70, damping 0.94) | 慢速氛围位移 |
| `Motion.fade` | easeOut(0.30) | 淡入淡出 |

- 冒号 2s 呼吸（opacity 1 ↔ 0.55），秒环每秒平滑推进。
- 防烧屏：每 30 分钟整体平移 1pt，3s 完成。
- 所有动效在 `AccessibilityReduceMotion` 下退化为交叉淡入或直接切换。
- 没有任何「无限旋转/闪烁」。

## 6. 交互模型

- 只有一个屏幕，没有导航栈。
- 点击时间舞台空白处 = 进入/退出沉浸模式（面板与状态条淡出，时间放大 3%）。
- 右上齿轮（面板 header 内）打开设置。
- 面板底部胶囊切换器在 5 个面板之间切换：今日 / 接下来 / 专注 / 世界时钟 / 服务器。
- 触摸反馈在按下瞬间发生（`PressableStyle`），不等抬手。

## 7. 禁止清单

- 紫蓝渐变（作为背景/装饰）、渐变文字（**唯一例外**：`悬浮蓝` 预设的数字渐变——那是 iOS StandBy 的还原，属于「被显示的内容」，不是装饰）、发光堆叠、玻璃拟态滥用。
- emoji 当图标（只用 SF Symbols）。
- 居中大标题 + 三列卡片模板。
- Lorem 占位文案、营销话术。
- 每个区块都居中；本设计全程左对齐 + 单一右栏。
- 阴影做装饰（只用于把卡片从画布上分离）。
- 二级菜单超过一层。
- 在视图里硬编码颜色 / 字号 / 字重 —— 一律从 `Theme` 或 `skin` 取。

## 8. 验收

1. 1440 / 1366 / 1024 宽度下无横向溢出，时间不换行。
2. CLS ≈ 0（首屏无布局跳变）。
3. 动效无 >500ms 的进场；无 `transition: all` 等价物。
4. 减少动态效果开启后，所有动画退化为淡入。
5. iPad 竖屏被锁定为横屏（Info.plist 强制），全屏无状态栏。
6. 深色下连续常亮 8 小时，无残留影像（防烧屏位移生效）。
