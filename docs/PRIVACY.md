# 隐私说明

> 结论先行：Meridian **不采集任何数据**。没有账号、没有统计 SDK、没有崩溃上报、没有广告、没有第三方网络请求。它只做两件事——显示时间、和你自己配置的服务器交换待办。

---

## 1. App 会接触到的数据

| 数据 | 存在哪 | 为什么 |
| --- | --- | --- |
| 服务器地址 + 口令 | 本机 `Application Support/Meridian/state.json` | 连接你自己的服务 |
| 待办（标题/时间/优先级/完成状态） | 本机同上 + 你的服务器 `data.json` | 核心功能 |
| 外观设置（皮肤/背景/布局） | 本机同上 | 不必每次重设 |
| 环境光读数 | **仅内存**，不落盘 | 自动调亮度 |

**没有**任何字段会离开"你的设备 ⇄ 你的服务器"这条链路。

---

## 2. App 不会做的事

- 不注册账号、不登录第三方服务；
- 不接入任何分析/埋点/崩溃收集 SDK（项目零第三方依赖）；
- 不上传设备型号、系统版本、使用时长；
- 不读取通讯录、照片、位置、剪贴板、健康数据；
- 不在后台联网（进后台即停同步与传感器）；
- 不向除你填写的地址之外的任何主机发请求。

可以自己验证：抓包只会看到你配置的那一个 host；`server/meridian-server.mjs` 里也没有任何外发请求。

---

## 3. 相机（环境光自适应）

iOS **没有公开的环境光传感器 API**。`UIScreen.brightness` 是屏幕背光，不是环境光；lux 数据被系统独占，第三方读不到。

所以"按环境光调亮度"只有两条路，本项目都做了，且都说明清楚：

### 模式 A：屏幕背光（默认）

- 读 `UIScreen.brightness` 与 `brightnessDidChangeNotification`；
- **完全不碰相机**，无需权限，功耗近似 0；
- 局限：屏幕亮度同时也受你手动调节影响，所以它是"代理"不是"测量"。

### 模式 B：精确测光（可选，默认关）

开启后：

- 仅用**前置摄像头**；
- **每 30 秒采样 0.35 秒**，其余 29.65 秒相机完全断电（`stopRunning()`）；
- 只读取画面 **Y 平面（亮度）的平均值**，按 16×16 步长采样后归一化；
- **不保存任何帧、不写文件、不上传、不录视频**；
- 采样结果与屏幕读数按 0.7 : 0.3 融合，用于决定界面亮度。

权限被拒绝时静默退回模式 A，不会反复弹窗、不会功能失效。

在「设置 → 显示 → 环境光自适应」里可以完全关闭这两条路径。

## 4. 网络与明文 HTTP

- App 允许 `http://`（个人服务器常见于局域网/IP 直连）。这是有意的取舍：**方便优先**；
- 公网部署建议用 HTTPS。若用自签证书，App 提供「信任自签名证书」开关——它**只对你在设置里填的那个 host 生效**，其他域名仍走系统默认校验；
- 该开关的实现见 `ios/Meridian/Sync/TrustingSession.swift`：`didReceive challenge` 里仅当 host 命中白名单且开关开启时接受 `serverTrust`，否则 `performDefaultHandling`。

> 权衡说明：接受自签证书 = 防路上的窃听，但**不防服务器被替换**。若要更严，可改成证书指纹固定（把服务器证书 SHA-256 写进 App），代码里预留了扩展位置。

---

## 5. 数据在哪、怎么删

| 端 | 位置 |
| --- | --- |
| iPad | `Application Support/Meridian/state.json`（沙盒内） |
| 服务器 | `server/data.json`（或部署时 `MERIDIAN_DATA` 指定的路径） |
| 门户/下发页 | 静态文件；口令只存在手机浏览器 `localStorage` |

- **覆盖安装**（同 bundle id）会保留 App 容器，数据不丢；
- **删除 App** 会清空本地数据，服务器上的 `data.json` 不受影响；
- 想彻底清除：删 App + 删服务器 `data.json` + 清浏览器站点数据。

---

## 6. 第三方

- App：**零第三方库**；
- 服务器：**零 npm 依赖**（只用 Node 内置模块）；
- 门户/下发页：无外链 CDN、无字体外链、无统计脚本。

---

## 7. 一句话

数据不出你的设备与你的服务器；相机只在你说"要精确测光"时短暂睁眼，且只看亮度。
